# Power & Solar B2B Website

A production-ready React + TypeScript + Vite website for a power and energy solutions company with a generator business and expanding solar energy division.

## Stack
- React
- Vite
- TypeScript
- React Router
- Lucide React

## Features
- Multi-page B2B corporate website
- Responsive navigation and mobile menu
- Quote and contact enquiry forms
- Supplier/partner enquiry form
- Centralized editable company configuration
- SEO metadata ready structure
- Netlify deployment ready

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Netlify deployment
See the file [README-deploy.md](README-deploy.md) for step-by-step deployment instructions.

## Safe deployment guidance
- Keep secrets out of the frontend code.
- Do not put API keys or backend credentials in browser files.
- Use environment variables only for public values.
- For future lead handling, connect the form to a secure backend or email/CRM service.

## Important
This project intentionally uses placeholders for company facts, addresses, phone numbers, emails, and project details. Update the values in the configuration file before going public.
